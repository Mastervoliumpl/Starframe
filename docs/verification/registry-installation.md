The manager parses closed Lua, BepInEx 5, Map and AI declarations. Game-relative mapped paths must also fit the existing 240-character deployment limit.

`packages::prepare_registry_archive` uses a verified available release, its exact hash/size and its approved plan. It reads only the hash-keyed saved registry archive, extracts into owned staging through the existing guarded ZIP implementation, checks DLL headers without loading code, and rejects nested archives or executable content in Lua/Map/AI packages. It verifies any existing deduplicated content before reuse and retains changed files for repair. Failure cleans owned staging; cleanup failure returns an error with the retained staging ID. Cancellation checks occur during hashing, extraction and before content promotion.

It prepares the declared package on a blocking worker, then checks current authentication cancellation, fresh signed approval, the original exact identity and the installation declaration again before commit. Registry references retain numeric ModIDs and UUID ReleaseIDs and are not converted to old catalog IDs. Cleanup retains artifact bytes while any installed registry release still references them.
