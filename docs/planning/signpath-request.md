## Description

Starframe is a free, open-source desktop mod manager for Sanctuary: Shattered Sun. It helps players find curated mod releases, manage local imports, organize ordered collections and launch the game. It also manages the in-game integration and settings interface. Mod files come from their authors' sources, and each catalog release is approved individually by the maintainer.
