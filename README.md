# Starframe
Starframe is a mod manager for Sanctuary: Shattered Sun

The desktop foundation is in development at `0.1.0-dev.1`: a minimal Tauri window with plain Svelte, TypeScript and Vite, backed by Rust. Mod management and game integration are not available in this build. Milestone 0.1.0 is active, with live state, storage and game discovery next. See [development setup](DEVELOPMENT.md#desktop-development) for prerequisites and commands, and [version preparation](DEVELOPMENT.md#versions-and-change-history) for build metadata checks.
